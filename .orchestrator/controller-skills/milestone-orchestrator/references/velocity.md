# Interpreting velocity facts

Read for UNKNOWN facts, disputed ready-idle qualification or held PASS counts.
`velocity-metrics.ps1` owns census/reduction, not a second host algorithm.

`committed-product-milestone/v1` counts every issue kind in open committed
commerce/mobile outcomes, except platform-held, parked and policy-excluded
CI/controller-evidence outcomes. Canonical controller ownership never expires
with the observation window; kind relabels do not invent late-product history.

Actionable ready-idle requires current trusted `issue-readiness/v1` accepted by
main's `consumeIssueReadinessReceipt`, current-brief independent semantic PASS,
resolved prerequisites and committed window/backfill admission. The host may
pass already-verified candidate evidence via `-DispatchQualificationPath`;
this is transient, not a new readiness ledger. Bind issue/repository/node,
revision/body hash, all milestone fields, trusted checker/workflow artifact,
semantic review and admission. Artifact presence/comments/prospective verdicts
alone are not authority. Summary consumes evidence, never launches workflows or
a backlog corpus sweep. Unknown is not ready or proof that no ready work exists.

FLOOR counts issues with agent-owned next steps, not raw lane count. A validated
active hold on an exact-head PASS PR is held, not ready-idle or queue-only flow;
independent live lane/CI/unblocked PR can still flow once. Record each held/idle
identity with same-cycle action/reason and exact observation timestamp. A deferral
adds no native marker. Apply blocker/operator labels only for actual causes;
closed blocker stops blocking, operator status clears only after action proof.

Incomplete facts can prove FLOOR MET only when every gap is runtime-allowlisted
additive-only or proven issue-local and enough unaffected flowing witnesses
remain. Unrecognized/future gap kinds keep UNKNOWN; no blanket subtraction.
`floorProofIssues` are proof witnesses, diagnostic flow/backlog are not.
Below floor with incomplete authority remains UNKNOWN, not false UNMET/no-work.
Qualification never erases flow or holds; historical diagnostic observations do
not gain current ready-idle meaning retroactively. Repair named gaps directly.

DROUGHT is no product merge for 48 hours, re-armed each further 48 hours.
Diagnose directly; repair the blocker or simplify process. Only an external
block on Todd's priority warrants a priority question. Do not auto-revert or
add rules merely because telemetry misses a target. Weekly outcome summary:
product merges, hours since last merge, flowing issues, what changed; no new
Todd request. No repeated retrospective proof package is required.
